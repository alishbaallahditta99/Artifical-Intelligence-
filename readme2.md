# Context-Aware Chatbot Using RAG

## Objective
To build a chatbot that can understand PDF documents and answer questions using Retrieval-Augmented Generation (RAG).

---

## Features
- PDF document processing
- Text chunking
- Embedding generation
- FAISS vector database
- Semantic retrieval
- LLM-based response generation

---

## Tools Used
- Python
- FAISS
- Sentence Transformers
- HuggingFace Transformers
- PyPDF

---

## Methodology
1. Load PDF file
2. Extract text
3. Split into chunks
4. Convert text to embeddings
5. Store embeddings in FAISS
6. Retrieve relevant chunks
7. Generate response using LLM

---

## Results
The chatbot successfully retrieves context-based answers from documents.

---

## How to Run
1. Install dependencies
2. Run notebook
3. Upload PDF
4. Ask questions
